# Attributions

This project includes components derived from [shadcn/ui](https://ui.shadcn.com/),
used under the [MIT licence](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md).
See `src/app/components/ui/`.

Placeholder product and editorial photography comes from
[Unsplash](https://unsplash.com), used under the
[Unsplash licence](https://unsplash.com/license). These images ship with the
seed data so a fresh installation matches the design; replace them with the
boutique's own photography through the admin area before launch.

Typefaces are served by [Google Fonts](https://fonts.google.com): Playfair
Display, Cormorant Garamond, Cinzel, Inter and Great Vibes. The display headings
request a licensed face named "Boston Angel" first and fall back to Great Vibes,
which is what renders unless that font is self-hosted.
