============================================================
DATA INTEGRITY
============================================================

This is an ecommerce application.

Data integrity is critical.

Use database transactions wherever multiple related operations must succeed together.

For example:

Order creation should safely handle:

1. Validate authenticated customer.
2. Retrieve products from database.
3. Validate product availability.
4. Validate quantities.
5. Calculate prices server-side.
6. Validate discounts.
7. Calculate final total.
8. Reserve/decrease inventory appropriately.
9. Create order.
10. Create order items.
11. Create payment record.
12. Commit transaction.

If a critical step fails, the database must not be left in an inconsistent state.

Never trust:

- product prices from frontend
- discount amounts from frontend
- stock information from frontend
- final order totals from frontend
- user roles supplied by frontend

The backend is authoritative.
